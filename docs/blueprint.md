# **App Name**: NarrativeFlow

## Core Features:

- Full-screen Section Management: Renders 5 distinct full-height (100vh) sections, each designed for cinematic content presentation.
- Video Background Integration: Embeds looping, muted, and inline-playing background videos into each section with object-fit: cover to ensure full-screen coverage.
- Content Overlay for Readability: Applies a dark, semi-transparent CSS overlay above background videos to enhance text contrast and maintain readability.
- Centered Text Display: Positions all textual content centrally within each presentation section for visual focus and clear communication.
- Scroll-Snap Navigation: Implements smooth scroll-snap behavior, ensuring each section aligns precisely into view upon user scroll for a controlled presentation flow.
- Dynamic Text Fade-in Animation: Triggers a smooth fade-in animation for section text elements when the user scrolls into the corresponding full-screen view.

## Style Guidelines:

- A dark color scheme evokes a cinematic and professional feel, enhancing focus on content.
- Primary color: A deep, muted indigo blue (#2E2E66), chosen for its professional and innovative undertones.
- Background color: A very dark blue-gray (#16161C), providing a consistent and subtly themed canvas that anchors the primary hue.
- Accent color: A muted sky blue (#66B2CC), offering a cool, gentle contrast for highlighting key elements without visual dominance.
- Text Overlay: A dark, semi-transparent overlay using black with approximately 60% opacity (rgba(0, 0, 0, 0.6)) ensures high readability of text over video backgrounds.
- Headline and body font: 'Inter' (sans-serif) for its modern, highly legible, and objective aesthetic, perfectly suited for impactful presentation text.
- Each content section will occupy 100% of the viewport height and width, providing an immersive, full-screen experience, with content vertically and horizontally centered.
- Subtle and elegant fade-in transitions for text elements will be applied upon entering a section, reinforcing the cinematic feel without distracting from the message.
